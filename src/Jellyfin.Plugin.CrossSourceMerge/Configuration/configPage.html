Sources

Every row is one folder. Rank decides which medium wins - lower number first; it orders the sources and decides whose title and year name the folder. It does not appear in file names (Title (Year) [tmdbid-123] - 2 Stream.mkv). The source tag is the name an entry carries in the target tree - it must be unique per media type and may repeat across movies and series (3 NAS in both trees). The default category decides where a new entry from this folder goes. Shadow means: entries of this source stay in place even while it is unreachable.

Categories

Categories are additional target folders in the same tree. Pattern maps titles automatically whose title or source folder contains one of the words (semicolon separates them). There is exactly one standard per media type - everything without its own category goes there.

Targets without a source

What sits in the target tree but did not show up in the last plan: folders that no longer carry a title, and files nobody needs any more - leftovers of an old naming rule, for instance. The comparison uses the last run's list, not the sources; that is fast and spares the NAS. Entries are moved to <target>-alt/aufraeumen/<date>, nothing is deleted.

Erkennung

Title, year and id are read from the folder name, from .nfo files and from the Jellyfin library. A key is only needed for titles that are unknown everywhere - or for the list of missing mappings.

Without a key the lookups at TMDB, IMDB and TVDB stay off; everything else keeps working.

Only needed for the OMDB provider. IMDB and TVDB ids are resolved through TMDB so the target folder carries an id Jellyfin understands.

Left empty means: titles and descriptions in the language the Jellyfin server is set to. A value such as en-US overrides that.
